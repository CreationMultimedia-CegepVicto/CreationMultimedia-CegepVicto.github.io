    Semaine 7 — Exercice : Premier montage complet

    Objectif

    Appliquer les trois étapes du montage professionnel — dérushage, ours, construction — sur vos propres images tournées pendant la relâche, et produire un premier montage de 30 à 60 secondes.

    Durée estimée

    2 heures

    Contexte

    Vous avez du matériel brut. Vous allez maintenant travailler comme un monteur : visionner, sélectionner, assembler, puis affiner. L'objectif n'est pas la perfection — c'est de comprendre le processus et d'avoir un résultat concret à la fin de la séance.

    Matériel nécessaire : vos vidéos tournées pendant la relâche, accessibles depuis votre poste de travail.

    Étape 1 : Préparation du projet (10 min)

    Ouvrir DaVinci Resolve et créer un projet

    1. Ouvrez DaVinci Resolve — vous arrivez dans le Project Manager
    2. Créez un nouveau projet : New Project
    3. Nommez-le H26_VotreNom_PremierMontage
    4. Cliquez Create

    Organiser le Media Pool

    1. Allez sur la page Media (icône pellicule en bas)
    2. Dans le Media Pool, faites un clic droit > Add Bin et nommez ce dossier Brut
    3. Importez tous vos clips dans ce dossier : glissez-les depuis votre explorateur de fichiers

    Vérification : Tous vos clips apparaissent dans le Media Pool. Si un clip affiche une icône d'avertissement, c'est que DaVinci ne trouve pas le fichier — vérifiez que votre clé USB est bien branchée ou que vos fichiers sont au bon endroit.

    Étape 2 : Le dérushage (30 min)

    Le dérushage se fait avant de toucher à la timeline. Vous visionnez, vous notez, vous décidez.

    Visionner et noter — le dérushage sur papier

    Parce que vos clips sont probablement de longues séquences filmées en continu, vous allez d'abord faire un dérushage sur papier avant d'ouvrir la timeline. C'est une pratique professionnelle standard : noter les timecodes des moments intéressants pour ne pas chercher à tâtons dans vos clips une fois en montage.

    Le timecode est l'adresse temporelle d'un moment dans une vidéo. Dans DaVinci Resolve, il s'affiche en permanence dans le Viewer quand vous visionnez un clip — lisez-le simplement quand vous mettez la lecture sur pause.

    Comment faire :

    1. Dans le Media Pool, double-cliquez sur un clip pour le voir dans le Viewer
    2. Appuyez sur Espace pour lancer la lecture
    3. Quand vous repérez un moment intéressant, mettez sur pause et notez le timecode affiché dans le Viewer
    4. Faites de même pour la fin du moment
    5. Remplissez le tableau ci-dessous pour chaque clip

    Tableau de dérushage — à remplir sur papier ou dans un tableur :

    Fichier Timecode début Timecode fin Description Décision
    ✓ / ? / ✗
    ✓ / ? / ✗
    ✓ / ? / ✗
    ✓ / ? / ✗
    ✓ / ? / ✗
    ✓ / ? / ✗
    ✓ / ? / ✗
    ✓ / ? / ✗

    Légende : ✓ Garde · ? Peut-être · ✗ Rejette

    Conseil : Si vous hésitez, notez le moment et mettez ?. Il est toujours plus facile de ne pas utiliser un bon plan que de regretter d'avoir ignoré quelque chose d'utile.

    Organiser vos clips dans le Media Pool

    Une fois votre tableau complété, organisez vos clips dans DaVinci :

    1. Dans le Media Pool, faites clic droit > Add Bin et nommez-le Garde
    2. Créez un deuxième bin nommé Rejets
    3. Glissez chaque clip dans le bon dossier selon votre tableau

    À la fin du dérushage, vous devriez avoir :

    • [ ] Visionné tous vos clips au moins une fois
    • [ ] Rempli le tableau de dérushage pour chaque moment retenu
    • [ ] Classé vos clips dans Garde ou Rejets dans le Media Pool
    • [ ] Au moins 5 moments notés dans votre tableau

    Étape 3 : L'ours (20 min)

    L'ours, c'est le premier assemblage. Vous placez vos plans dans l'ordre sans chercher la précision — l'objectif est de voir si la structure fonctionne.

    Passer sur la page Edit

    Cliquez sur l'icône Edit (clap de cinéma) en bas de l'écran.

    Extraire les bons moments avec les points d'entrée et de sortie

    Vos fichiers sont probablement de longues séquences continues. Votre tableau de dérushage indique les timecodes des moments que vous voulez garder — vous allez maintenant les extraire un par un avant de les déposer sur la timeline.

    Pour chaque ligne ✓ de votre tableau, dans l'ordre prévu :

    1. Dans le Media Pool, double-cliquez sur le fichier source pour l'ouvrir dans le Viewer source (en haut à gauche)
    2. Naviguez jusqu'au timecode de début noté dans votre tableau
    3. Vous pouvez cliquer directement sur l'affichage du timecode dans le Viewer et taper la valeur
    4. Ou scrubber manuellement la barre de lecture
    5. Appuyez sur I pour marquer le point d'entrée — une marque apparaît sur la barre de lecture
    6. Naviguez jusqu'au timecode de fin
    7. Appuyez sur O pour marquer le point de sortie
    8. Glissez le clip depuis le Viewer source vers la timeline — DaVinci ne dépose que la portion comprise entre I et O, pas le fichier entier

    Répétez pour chaque moment retenu dans votre tableau.

    Important : Les points I et O se réinitialisent à chaque nouveau clip ouvert dans le Viewer. Vous pouvez aussi appuyer sur Alt + I ou Alt + O pour effacer un point si vous vous êtes trompé.

    Évaluer la structure

    Regardez votre ours et posez-vous ces questions :

    • Est-ce qu'on comprend de quoi il s'agit dès le début?
    • Est-ce que l'ordre des plans a du sens?
    • Y a-t-il des plans qui devraient être déplacés?
    • Y a-t-il quelque chose d'important qui manque?

    Réorganisez si nécessaire — glissez les clips pour les repositionner sur la timeline.

    À la fin de l'ours, vous devriez avoir :

    • [ ] Tous vos moments retenus sur la timeline, dans l'ordre, extraits avec I et O
    • [ ] Une structure qui raconte quelque chose, même imparfaitement
    • [ ] Regardé le résultat une fois de bout en bout

    Étape 4 : La construction (50 min)

    C'est maintenant que vous affinez. Vous allez travailler coupe par coupe pour arriver à un montage de 30 à 60 secondes.

    Raccourcir les clips avec le Trim

    La plupart de vos clips durent probablement trop longtemps. Il faut enlever les secondes inutiles au début et à la fin de chaque plan.

    1. Avec l'outil de sélection (A), approchez votre curseur du bord droit d'un clip sur la timeline
    2. Le curseur se transforme en flèche de redimensionnement
    3. Glissez vers la gauche pour raccourcir la fin du clip
    4. Faites de même avec le bord gauche pour raccourcir le début

    Répétez pour chaque clip jusqu'à ce que chaque plan dure juste le temps nécessaire.

    Repère : Un plan moyen dure généralement entre 2 et 5 secondes dans un montage dynamique. Un plan large peut durer un peu plus longtemps pour installer l'ambiance.

    Couper avec le Blade

    Si un clip contient un bon moment entouré de parties inutiles, utilisez le Blade pour isoler ce que vous voulez garder.

    1. Appuyez sur B pour activer l'outil Blade
    2. Cliquez au début de la partie à garder — le clip se coupe
    3. Cliquez à la fin de la partie à garder — le clip se coupe à nouveau
    4. Appuyez sur A pour revenir à l'outil de sélection
    5. Sélectionnez et supprimez les parties inutiles avec Shift + Delete (Ripple Delete — referme le trou automatiquement)

    Vérifier la durée totale

    La durée de votre montage apparaît dans la barre de la timeline (en haut à gauche de la zone de montage, ou dans le Viewer). Visez entre 30 et 60 secondes.

    • Si votre montage est trop long → raccourcissez les plans les moins essentiels, ou retirez un clip entier
    • Si votre montage est trop court → vérifiez si des plans dans Rejets pourraient finalement être utiles

    Regarder et ajuster

    Regardez votre montage plusieurs fois. À chaque visionnement, notez ce qui accroche — un plan trop long, une coupe abrupte, un moment qui manque de clarté — et corrigez-le.

    À la fin de la construction, vous devriez avoir :

    • [ ] Un montage entre 30 et 60 secondes
    • [ ] Utilisé le Trim pour raccourcir au moins 3 clips
    • [ ] Utilisé le Blade sur au moins 1 clip
    • [ ] Regardé le montage au moins 3 fois de bout en bout

    Étape 5 : Sauvegarder (5 min)

    1. Ctrl + S (Windows) ou Cmd + S (Mac) pour sauvegarder le projet
    2. Si vous travaillez sur un ordinateur de la bibliothèque, exportez votre projet :
    3. Retournez dans le Project Manager
    4. Clic droit sur votre projet → Export Project
    5. Sauvegardez le fichier .drp sur votre clé USB, à côté de vos fichiers vidéo

    Points à retenir

    Le processus

    • Dérushage d'abord — ne jamais monter avant d'avoir tout vu
    • L'ours valide la structure — ne pas affiner avant que l'ordre soit bon
    • La construction est itérative — regarder, corriger, regarder encore

    Les raccourcis essentiels

    • A — Outil de sélection
    • B — Blade (couper un clip)
    • I — Marquer le point d'entrée dans le Viewer source
    • O — Marquer le point de sortie dans le Viewer source
    • Espace — Lecture / pause
    • Shift + Delete — Ripple Delete (supprimer sans trou)
    • Ctrl/Cmd + Z — Annuler

    Problèmes courants et solutions

    Mes clips n'apparaissent pas dans le Media Pool

    → Vérifiez que votre clé USB est bien branchée. Essayez de glisser à nouveau les fichiers depuis l'explorateur.

    J'ai supprimé un clip par erreur

    → Ctrl + Z annule la dernière action. Répétez si nécessaire.

    Mon montage dure 3 minutes et je n'arrive pas à le raccourcir

    → Soyez impitoyable : chaque plan doit gagner sa place. Si un clip ne fait pas avancer l'histoire ou ne montre rien de nouveau, retirez-le.

    Il y a des trous noirs dans ma timeline

    → Vous avez supprimé des clips avec Delete au lieu de Shift + Delete. Sélectionnez le trou noir, faites Shift + Delete pour le refermer.

    Je ne sais pas dans quel ordre mettre mes plans

    → Pensez à l'activité que vous avez filmée : qu'est-ce qui s'est passé en premier? Commencez par un plan large qui situe l'action, puis montrez les étapes dans l'ordre naturel.
